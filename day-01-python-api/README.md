# Python API Explorer (V2)

## Overview
This project is a beginner-friendly Python application that interacts with a public API to fetch and display user data. It includes features like viewing user details, searching by name, and exporting data to a CSV file.

## Features
1. **View user by ID**: Fetch and display details of a user by entering their ID (1-10).
2. **View all users**: Fetch and display details of all users.
3. **Search by name**: Search for users by name (case-insensitive, partial match).
4. **Export users to CSV**: Export all user data to a CSV file located in `day-01-python-api/exports/users.csv`.
5. **Exit**: Exit the program.

## Requirements
- Python 3.x
- `requests` library
