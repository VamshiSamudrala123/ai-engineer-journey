# Project 04 — InsightForge AI: Banking Intelligence Agent

A multi-tool AI agent for banking transaction analysis,
financial intelligence, anomaly investigation, and reporting.

## Planned Technology Stack

- Python
- Google Gemini function calling
- DuckDB
- Pandas
- Plotly
- Streamlit
- Automated testing

## Dataset

IBM Transactions for Anti Money Laundering (AML)
from Kaggle.

The dataset contains synthetic financial transactions.

## Project Goals

- Analyze large banking datasets with SQL
- Investigate account and transaction patterns
- Build an AI agent that selects multiple tools
- Generate interactive visualizations
- Produce evidence-backed analytical reports
